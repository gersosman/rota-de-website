# Faz 3

Görsel ön değerlendirme, ilk taraf ölçümü ve WhatsApp Business Cloud API.

Kişisel telefon yayımlanmaz. WhatsApp düğmesi, Meta işletme numarası doğrulanmadan açılmaz.

Webhook `GET/POST /api/whatsapp/webhook` imza ve doğrulama jetonu ister. Aynı mesaj ikinci kez dosya açmaz. Yönetici cevabı 24 saatlik pencerenin dışında gitmez. Toplu pazarlama gönderimi yoktur.

Telegram masası durur. İki kanal `/admin/mesajlar` altındadır.
